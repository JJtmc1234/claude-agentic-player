9. FACTORIO SPECIFICS (hard-won, easy to forget)
------------------------------------------------------------------------

- Inserter `direction` = the side it PICKS FROM (not where it drops).
  For "pick from north, drop south": direction = 0.
  For "pick from west, drop east": direction = 12.
  Getting this wrong tanks logistics silently.
- 2x2 producer + 1x1 inserter alignment: for a stone-furnace at center
  (px, py) fed by an inserter to its south:
    * inserter target Y = py + 1 (snaps to py + 1.5)
    * NOT py + 2 (that puts the inserter one tile too far south with an
      empty pickup tile — status 32 waiting_for_source).
- burner-mining-drill drop offset (Factorio 2.0): south-facing drop is at
  `center + (0, 1.296875)` — about 1.3 tiles south of center, NOT 2.
  This is the FIRST row south of the drill's south edge. Direct
  drill→chest layout (no inserter): drill at (cx, cy) south, chest at
  (cx + 0.5, cy + 1.5). Direct drill→furnace also works because a 2x2
  furnace at (cx, cy + 2) has its top-north-tile at cy + 1 which catches
  the drill's drop.
- Entity status codes verified 2026-06-20:
    1  working
    12 full_output
    17 no_power
    18 no_ingredients (furnace: no input item)
    19 no_fuel (burner)
    21 no_minable_resources (drill on empty tile)
    26 low_power / item_ingredient_shortage (asm)
    27 full_output (boiler variant)
    31 missing_science_packs (lab)
    32 waiting_for_source_items (inserter can't pick)
    34 waiting_for_space_in_destination (inserter can't drop)
    53 no_fuel (alt code)
    54 no_power (alt code)
  Always decode via `defines.entity_status` table before guessing.
- 3x3 entities (asm-1, lab): position given to `create_entity` is the
  entity center. Weird snapping — passing `{-38, 42}` may result in the

11. COMMON PITFALLS
------------------------------------------------------------------------

- Bash tool on Windows throws cygwin fork errors on chained pipes / heavy
  ops. Default to PowerShell for shell work; use Bash only for short
  one-shots. File ops via Glob/Grep/Read/Edit avoid it entirely.
- PowerShell: single-quoted here-strings `@'...'@` for multiline literals
  (the closing `'@` MUST be at column 0). For git commit messages with
  special characters, write to temp file + `git commit -F <tempfile>`.
- Placement failures on ore patches — the mod's `mine_resources=True`
  flag uses `e.destroy()` on the resource, LOSING the whole tile. Prefer
  placing entities on non-ore tiles (drill on ore is fine — drills don't
  need to clear it).
- Long-distance walks: `walk_chunked(x, y, chunk_size=25-30)` breaks a
  long walk into chunks so pathfinder doesn't time out. Bare `walk_to`
  fails on >~50 tile distances.
- Character death — no corpse persists past ~15 min. Respawn: use a
  variant of `_spawn_claude.py` that skips the starter kit (empty
  respawn) so you don't trip the auto-classifier for "cheating".
