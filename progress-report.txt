## 2026-05-31 (later evening) — RCON sentinel fix + tight BC fine-tune

- Factorio was logging "invalid message type 0" warnings every RCON call — the mirror-packet trick was sending type-0 (RESPONSE_VALUE) packets from the client side, which Source/Factorio considers invalid even though some servers tolerate it.
- Fix: switched the sentinel packet from type-0 RESPONSE_VALUE to a valid type-2 EXECCOMMAND with body "/silent-command return" (cheap no-op). Same end-of-stream marker, no log spam.
- Re-measured RTT: **16.2 ms/call** (was 67ms with mirror trick, 1018ms before any fix). ~63x speedup over the original.
- chain_v3 (ent_coef 0.10, lr 2e-4) drifted away from BC: first 30 eps mean -38 → last 30 -59. PPO was exploring too far from BC imprint. Stopped at ~1500 steps.
- Added `--target-kl` flag to train_masked.py so we can early-stop policy updates when KL diverges (useful after BC).
- Launched chain_v4: ent_coef=0.02, lr=5e-5, target_kl=0.01 — tight fine-tune to preserve BC bias.

## 2026-05-31 (later) — RCON 15x speedup + chain_v2 launch

- Diagnosed chain_v1 training slowness: bridge/rcon_client.py used drain_timeout=1.0s per call, so every RCON round-trip waited a full second to confirm "no more packets". Average measured RTT 1018ms.
- Rewrote `command()` to use the Source RCON "mirror packet" trick: send the real command, then an empty RESPONSE_VALUE packet with a tracked id. Server echoes the real response, then echoes the mirror — at which point we know the real response is fully delivered. drain_timeout drops to 50ms (safety net only).
- New measured RTT: 67ms/call. ~15x speedup. Expected training rate jumps from ~0.4 fps to ~6 fps.
- Added bridge/rl/callbacks.py (BestCheckpointCallback saves a separate _best.zip when ep_rew_mean improves; EpisodeJsonlLogger writes one JSON line per finished episode to checkpoints/<name>_episodes.jsonl for plotting/eval).
- Added bridge/rl/grid_extractor.py (small 2-layer CNN over the 8x8x12 grid + 3 globals, feeds into a 128-dim feature head) and `--policy cnn` flag in train_masked.py.
- Added bridge/rl/eval_checkpoint.py for deterministic N-episode evaluation runs.
- Launched chain_v2: 30k steps, CNN policy, ent_coef=0.15, save_every=512, all new callbacks. ETA ~1.3 hr instead of ~30.
