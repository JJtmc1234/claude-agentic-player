CORE RULES (all agents)
--------------------------------------------------------------------------

- Update your own section on every substantive action.
- Employees NEVER address the Human directly. All Human-facing
  updates go through Manager.
- Manager NEVER edits code as an implementer — Manager assigns
  Employees to do implementation. Exception: docs (context.txt,
  bug-log.md, merge-log.md) and merge commits.
- Placement conflicts: never assign two Employees to place entities
  in the same tile-region in the same batch. See tile-lock design
  in `thoughts.txt`.

  and take_from_chest can race on shared state.

- Buffer chest from JJ at (-6.5, -32.5) — check periodically for
