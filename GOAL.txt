Claude Agentic Player — Project Goal
====================================

Make Claude able to join a Factorio multiplayer server and control a player
character, so Claude can play alongside me as a co-op helper / assistant /
builder.

Core vision
-----------
- I host (or rent) a Factorio dedicated server.
- Claude connects to that server as a player (or controls a player-like
  entity inside the game).
- Claude can perceive the game world (map, inventory, signals, alerts) and
  take actions (move, mine, build, craft, place blueprints, fight, drive,
  pilot rockets/platforms).
- I play normally on the same server; Claude is a teammate I can talk to in
  natural language ("go mine that iron patch", "build me a yellow belt bus
  here", "defend the north wall while I go to Vulcanus").

Target mod targets
------------------
- Space Age (Factorio 2.0 expansion) — primary.
- Krastorio 2 (K2) — secondary.
- Space Exploration (SE) — secondary.
- Should not be tightly coupled to a single mod's recipes/entities; design
  the agent so the world model is read dynamically from the game state
  rather than hardcoded.

What "good" looks like
----------------------
- I can say something in chat or in a side channel and Claude carries it out
  without me babysitting every click.
- Claude understands long-horizon goals (build a green-circuit factory) and
  decomposes them into actions on its own.
- Claude is safe in my base: doesn't dismantle my stuff, doesn't grief, asks
  before doing anything destructive or expensive.
- Latency is good enough that it feels like a real co-op partner, not a
  turn-based bot.

Non-goals (for now)
-------------------
- Beating speedrun records or playing optimally.
- Replacing me — this is co-op, not solo AI play.
- Working without a mod / purely through screen pixels. We'll lean on
  Factorio's Lua API and a companion mod where useful.
